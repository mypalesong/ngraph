    지식 그래프란?¶

    정의¶

    지식 그래프(Knowledge Graph)는 현실 세계의 정보를 엔티티(Entity)와 관계(Relationship)로 구조화하여 표현하는 시맨틱 네트워크입니다.

    핵심 특징¶

    1. 그래프 구조: 노드와 엣지로 데이터 표현
    2. 시맨틱 표현: 의미론적 관계 표현
    3. 상호 연결성: 모든 데이터가 관계로 연결
    4. 기계 판독 가능: 표준화된 형식으로 저장

    트리플 구조¶

    (주어) - [술어] -> (목적어)
(Subject) - [Predicate] -> (Object)

    지식 그래프 유형¶

    유형 설명 예시
    오픈 KG 공개 지식 그래프 DBpedia, Wikidata
    엔터프라이즈 KG 기업 내부 KG 고객 360, 제품 카탈로그
    도메인 특화 KG 특정 분야 KG SNOMED CT, Gene Ontology

    주요 표준¶

    • RDF: W3C 표준 데이터 모델
    • Property Graph: Neo4j 등에서 사용
    • SPARQL: RDF 쿼리 언어
    • Cypher: Property Graph 쿼리 언어
